# BiteDash Multi-Page Food Delivery Website

Pages:
- index.html — Home
- about.html — About
- menu.html — Menu + category filters + cart
- reviews.html — Reviews slider
- contact.html — Contact form

Shared assets:
- styles.css
- main.js

Features:
- Responsive multi-page navigation
- Font Awesome social/media/UI icons
- Light/dark mode
- Persistent demo cart using localStorage
- Menu filtering
- Review slider
- Mobile menu
- Contact form demo

The food/chef photos are loaded from Unsplash and Font Awesome is loaded from its CDN, so those require internet access.
